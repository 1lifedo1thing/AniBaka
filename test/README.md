# 测试

在项目根目录运行：

```sh
fvm flutter test --no-pub
fvm flutter analyze --no-pub
```

## 结构和保障范围

- `core/`：账号隔离、请求去重、存储恢复、匹配排序、规则解析与解码、HLS 安全过滤。
- `services/`：收藏同步、历史恢复、源迁移、凭证并发、媒体探测、种子解析、日志下载访问限制。
- `features/`：播放控制与配置迁移、选集换源、一起看同步、弹幕、页面状态保留、分页与返回手势。
- `support/`：现有应用依赖装配和真实 TS 分片前缀；只有使用方确实需要时才引用。

目前没有 `integration_test/` 或 Golden 测试。`.github/scripts/tests/` 中的发布签名测试
保护签名验证与打包顺序，单独保留，不纳入 Flutter 测试耗时。

## 维护约定

按模块添加有风险的行为场景，优先放入已有文件。验证输入、结果、状态变化和持久化结果，
不为类、字段或静态 UI 单独建测试。原生播放器、HTTP 和字体资源边界可以使用小型替身；
纯解析与配置测试无需初始化完整应用服务。

异步测试优先等待 Future、请求到达或状态通知。Widget 的 `pump` 推进虚拟时间，
`pumpAndSettle` 用于仍需完成的导航、滚动和弹窗动画。凭证竞争保留服务端短延迟以暴露并发覆盖；
保活停止测试观察一个心跳周期，不能省略后直接断言停止。它们都不作为性能指标。

## 本次精简

删除仅输出测量数据的弹幕/字体性能循环、主题与图标静态断言、固定着色器列表及源码字符串断言、
简单字段测试和重复规则结构断言。保留相应模块的行为测试；一起看的大批量性能用例缩成阻塞期间
连续收到快照的回归场景。合并重复宿主替身，移除无关的全局服务初始化与部分固定等待。

本机 Flutter 3.44.9、相同 `flutter test --no-pub --reporter expanded` 命令的单次观测：

| 指标 | 精简前 | 精简后 |
| --- | ---: | ---: |
| 测试文件 | 73 | 31 |
| Dart 文件（含辅助代码） | 75 | 33 |
| Dart 行数（含空行、注释） | 10,957 | 9,657 |
| 通过的测试项 | 328 | 278 |
| 命令总耗时 | 31.90 秒 | 19.50 秒 |

耗时减少约 39%，比较的是精简前后的完整测试套件，测试工作量有所减少；
单次观测受编译缓存和机器负载影响，不代表应用或真机播放性能。

`flutter analyze --no-pub` 仍报告原有的 `lib/api/request_cache.dart:75`
缺少花括号的 info；本次测试重构没有新增分析问题。
